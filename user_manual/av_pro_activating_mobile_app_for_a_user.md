**Enable Mobile App for the User**

**Edit User Settings**

- Navigate to the profile of the user you wish to enable mobile app
  access for.  

<!-- -->

- Edit the settings for the selected user to make changes.  

<!-- -->

- Check the box labelled AV PRO to activate this feature for the user.  

<!-- -->

- Click save to confirm and apply the changes.  

![](media/image1.png){width="6.268055555555556in"
height="4.352083333333334in"}  

**Logging into the Mobile App**  

**Enter Your Credentials**  

- Input your system username *(Note: This is case sensitive).* 

- Enter your system login password.

- Input the system name *(e.g., if the URL is
  "demo.assetvantage.com", enter "demo" as the system name).*

- After entering your credentials, you will be successfully logged into
  the mobile app.
