In report book print, data overlaps if the widgets are not
arranged/expanded fully to accommodate the data. To overcome this, we
have introduced a widget 'Full Page -- auto expand' which will auto
expand it\'s data only while printing the PDF.

**Finding the Report Book**

To navigate to the Report Book, go to 'Menu', and then 'Report Book'.

*To learn how to set up a dashboard and widgets on the Report Book,
please refer to the [Report book explained
article](https://support.assetvantage.com/hc/en-us/articles/4403260437393-The-AV-Report-Book-explained).*

**Adding this Widget**

- The user must drag the widget into the dashboard to make it appear
  there.

![](media/image1.png){width="6.268055555555556in"
height="2.892361111111111in"}

- 'Full Page -- auto expand' widget is of a page's size and is not
  resizable.

- Full page widget has all the reports viz. Wealth Register, Cumulative
  Multi Period Performance Report, Custom Multi Period Performance
  Report, Private Equity, Portfolio Performance Report, Capital Flow
  Report, Capital Flow Investment, Transaction By Account Report.

- On processing any of the report, full page widget may have scroll bar
  but it will expand row wise while printing PDF.

**Positioning this Widget**

- If user wants full page widget to be placed either at the top or
  bottom of the existing widget, then scroll bar should be placed either
  at the top or bottom of the dashboard respectively.

- If user wants full page widget to be placed in any of the pages in
  between (except first and last page), then user should set
  scrollbar\'s position in the middle of the existing widget.\
  Full page widget will be placed on the next page and all the below
  widgets will be pushed down.

- If user deletes full page widget, then widgets below full page widget
  will auto slide up to take up the deleted full-page widgets\' space.

**Note**: Full page widget supports only tabular data and doesn't
support any charts, images etc.
