**What is the Transactions by Account report?**

This report presents all the transactions of the selected ledger
account/accounts for a defined time-period. This report allows you to
select multiple ledger accounts and can be customized to include only
the desired information. 

**Finding the Transactions by Account report **

**Step 1 **

To generate this report, go to \'Menu,\' head to \'General Ledger,\' and
select 'Transactions By Account\'.

**Generating the Transactions by Account report **

**Step 2 **

**Selecting the Report Filter**

Users will have to select appropriate filters to obtain the desired
accounts: 

- **Account Type:** This dropdown list consists of all the Asset,
  Liability, Equity, Income, and Expense account types of the selected
  entity. 

- **Account:** This dropdown will enlist accounts corresponding to the
  selected Account Type.

- **Report Period:** This enlists all the financial years since
  inception. You can also run this report for custom dates by selecting
  the From and To dates.

- **Show Columns:** The report can be further customized by
  selecting/deselecting the desired columns (payee/payor, tags, position
  name, etc.) from the 'Show Columns' to be reflected in the report.

- **Detailed and Summary Reports:** You can either run a detailed report
  (displays every debit and credit transaction of the selected
  account/accounts along with running balance) or a summary report
  (displays cumulative debit and credit amounts of selected
  account/accounts along with running balance at the end of the selected
  period). \
  \
  *Tip: The summary report loads faster in case there are too many
  transactions. \*

**Checkboxes:**

- **Grid View:** This report can also be run in grid view by checking
  the \'Grid View\' checkbox in the filters before running the report.

- **Show only with Activity:** If this is checked, the report will only
  display those accounts where transactions (activity) have been
  reported during the selected period.

Report can be expanded for the required accounts by using the '+' icon
available on the left of the list of accounts. All the accounts can also
be expanded at one go using the expand button available at the top left

**Generating Transactions by Account on the Report book **

**Step 3 **

Go to 'Menu', 'Report Book', then to 'Add Widget', and finally, to the
'General Ledger' widget. 

![](media/image6.gif){width="6.268055555555556in"
height="3.5256944444444445in"}

**Step 4 **

Click the filter icon to get a pop-up that lets you select your report
type. There, choose 'Transactions by Account'. Select 'Template' from
the list, select 'Account Type' 'Accounts' and other details from the
filter and then click 'Process' to generate the report.

![](media/image7.png){width="6.268055555555556in"
height="3.2958333333333334in"}

*Note:\*

- * In 'Other Fields' you get a option 'Show DR/CR in single column'
  that let you see the 'Debit', 'Credit' & \'Running Debit\', \'Running
  Credit\' in single column as 'Amount' & 'Running Amount'
  respectively. *

- *'Hide Running Balance' checkbox helps to hide/show the Running
  Balances (\'Running Debit\' & \'Running Credit\') from the report.* 

**Generating Transactions by Account with COA template **

AV has the functionality to run the Transactions by Account report with
a Chart of Accounts (COA) templates defined for the Entity or Group on
the Report Book.

Want to know more about Chart Of Account features. Please refer to
 -** \**

**Step 5 **

You just have to choose from a list of Templates - 'None', 'Account
Type', 'IFRS', 'US GAAP' & Custom Templates defined for the Entity or
Group. Select the 'Account Type', 'Accounts' and other details from the
filter and then click 'Process' to generate the report.

![](media/image9.png){width="6.268055555555556in"
height="3.2958333333333334in"}

*Note:\*

- *Selecting 'None' will run the report without any COA template and
  will group the data Account wise.*

- *Selecting 'Account Type' will grouped the data at Class level i.e.
  (Assets, Liabilities, Equity, Income & Expense).*
