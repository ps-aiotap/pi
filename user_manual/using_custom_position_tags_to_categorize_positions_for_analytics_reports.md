**What are custom position tags?**

User-defined custom position tags help you map position tags as per
preference, and provide additional tagging options to help categorize
positions for various analytics reports.

*Tip: 5 more configurable position tags have been added in the Position
Master 'add/edit' screen, allowing you to tag these to a particular
position. *

**Setting up 'User Access Profile'**

**Step 1 **

Go to 'Menu', 'Settings', 'User Access Profile', and finally, to
'Position Tags'.

*Note:*

- *Checking the \'Add\', \'Edit\', and \'View\' boxes gives permission
  to add, edit, and see the tag respectively.*

- *User access rights given individually for Asset Class, Sector,
  Strategy, and Advisor have been removed, and are now covered under
  'User Access Rights' of 'Position Tags', along with user-defined
  tags. *

height="3.5256944444444445in"}

*For detailed information about 'User Access Profiles', please refer
to [this

**Finding positions tags\**

**Step 2 **

To navigate to the position tags, go to 'Menu', 'Masters', and then
'Position Tags'.

![](media/image2.gif){width="6.268055555555556in"
height="3.5256944444444445in"}

**How to configure position tags**

**Step 3 **

In the 'Position Tags' screen, you'll see all position tags - namely
Advisor, Asset Class, Sector, and Strategy - along with the 5 new custom
position tags.

![](media/image3.png){width="6.268055555555556in"
height="3.4770833333333333in"}

**Step 4 **

The 5 custom position tags will have default names from Position Tag 1
to Position Tag 5. Click the edit icon to change these names, which will
then be reflected in the Position Tags master screen, masters, and
drop-down filter of all relevant reports.

*Note: Duplicate display names are not allowed; add one and you\'ll
immediately be notified of the same by a validation message. *

![](media/image4.png){width="6.268055555555556in"
height="3.4770833333333333in"}

**Step 5**

To add/edit position tag filter values, head to 'Positions' in the
'Masters' section, and click the \'+\' icon to add a new position tag
filter value.

*Note: Custom tags will show a default 'No Tag' on all positions until
you customize it.*

![](media/image5.png){width="6.268055555555556in"
height="3.4770833333333333in"}

**Step 6**

New custom tags will move to the bottom of the list automatically.
Rearrange this order, including for Asset Class, Sector, Strategy, and
Advisor, according to your preference, using the \'drag and drop\' icon.
This order will be visible on the reports.

![](media/image6.png){width="6.268055555555556in"
height="3.4770833333333333in"}

**Step 7**

Add/select tags from the position master with the '+' button. Then,
simply update the position tag values from the drop-down and save them.

![](media/image7.png){width="6.268055555555556in"
height="3.4770833333333333in"}

![](media/image8.png){width="6.268055555555556in"
height="3.4770833333333333in"}

**Step 8**

Once tagged, the same will be visible on the position master screen,
analytics reports, and exports. These newly added tags will be available
as part of the 'Grid view' reports if 'All Position Tags' is selected
from the 'Show Column' option.

![](media/image9.png){width="6.268055555555556in"
height="3.4770833333333333in"}

**How to run reports with user-defined tags?**

**Step 9**

Select your primary and secondary group as per the newly added tags,
then run the reports.

![](media/image10.png){width="6.268055555555556in"
height="3.4770833333333333in"}

**Step 10**

Upon running the report, you'll see a consolidated view, with the tags
and their sequence/order as you've configured.

![](media/image11.png){width="6.268055555555556in"
height="3.488888888888889in"}

**Which reports are impacted?**

See the impact of position tags on the Wealth Register, Portfolio
Performance, Multi-Period Performance Report, Capital Flow by
Investments, Gains Report, Open Lot Report, Private Equity, Asset
Allocation, Investment Payout Register, Fixed Income, Custodian
Reconciliation, and Transaction by Account reports.

*Tip: The custom position tags can be edited simultaneously across
multiple positions, and will be part of the Position Master's Excel
export.* 

*Note: The custom tags feature is only available for Pro and Prime
licensees.*
