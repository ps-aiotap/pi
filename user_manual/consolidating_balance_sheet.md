A Consolidating Balance Sheet presents the assets, liabilities,
equities, incomes, expenses, and cash flows of multiple entities within
a group (as defined by the user) in a single view. This aids users in
comparing multiple balance sheets at the same time and provides a bird's
eye view of the group's financial condition.

This report is generally run for the end of reporting period**.**

**Finding Consolidating Balance Sheet**

Navigate to the  Consolidating Balance Sheet by going to 'Menu', then
'General Ledger', and finally,  \'Consolidating Balance Sheet'.

**Generating Consolidating Balance Sheet**

**Setting Templates**

Before you dive into generating a Consolidating Balance sheet, let\'s
set the template for it .There are predefined templates (US GAAP and
IFRS) readily available for an entity/ group but if user wants to
configure custom template, then it can be done from Chart of Accounts
(path: Menu \> Masters \> Chart of Accounts). Please refer [this
article](https://support.assetvantage.com/hc/en-us/articles/360018745738-Setting-up-and-customizing-chart-of-accounts-COA-using-the-base-GAAP-and-IFRS-templates).

** Selecting Report filters**

- User needs to select appropriate filters to run the Consolidating
  Balance Sheet for the selected group.

- Template dropdown has predefined US GAAP and IFRS template and will
  also reflect any custom template defined for the selected group by the
  user. Default template selected on group master will be selected by
  default.

- User can select the date as of which the report is to be generated and
  the currency and denomination in which the report is to be viewed.

- User has option to view the balance sheet at either cost or valuation
  basis.

*Note: Please ensure that the balance sheet is balanced the first time
as of the entities' book start date i.e. Assets should be equal to
Liabilities + Equity. The system creates double-sided journal entries
for all transactions after the book start date, to ensure that the
balance sheet is always balanced.*
