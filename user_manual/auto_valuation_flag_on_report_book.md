This flag allows user to know if reported valuation is using last
available valuation or computed auto valuations in all performance
reports

**How to enable Auto-Valuation**

This option is available under "Other fields" as "Show Auto Valuations
in Italic", once selected widget will display values in blue italic font
for auto computed values. This checkbox will be default unselected.

Available for all valuation columns for Wealth Register, Portfolio
Performance Report, Multi Period Performance Report, Private Equity
Report, Capital Flow by Accounts and Capital Flow by Investment Report.
