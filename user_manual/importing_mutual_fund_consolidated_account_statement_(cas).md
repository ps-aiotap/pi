**Applicability** : Customers with India based CAMS mutual fund
accounts.

**Steps to request and upload CAS statement**

**Step 1**

- Go to [**https://www.camsonline.com**](https://www.camsonline.com/)

- **Investor Service** \> **Statements **\> **CAS CAMS+Karvy+FTAMIL**

![](media/image1.png){width="6.268055555555556in"
height="2.3222222222222224in"}

If you have registered an email address in your folios across funds
serviced by CAMS, Karvy , FTAMIL and SBFS, you can use this Mailback
Service to obtain a consolidated PDF Account Statement at your
registered email address. For reasons of security the statement will be
encrypted using the password provided by you and emailed only to the
address provided earlier in your application form.

Please make the request as mentioned below:

- Select Statement type as Detailed (Includes transaction listing).

- Choose period as Specific period.

- For first time, you can choose the \'from date\' as your first
  investment date and \'to date\' as today's date.

- Select folio listing as With Zero balance folios. This will cover all
  folios including folios which have been redeemed earlier.

- Enter your registered email id in Email field.

- Keep PAN field blank as statement will capture all PANs which are
  registered against email id.

- Please enter password and word verification to request the CAS
  statement.

![](media/image2.png){width="6.268055555555556in"
height="3.9694444444444446in"}

**Uploading Mutual Fund CAS Statement**

**Step 2**

Once you receive the password protected CAS statement, you need to
convert the same into an AV excel format from File convert.

- Go to **Menu **\> **Transactions **\> **File converter**.

- Select password protected file checkbox.

- Upload the PDF file through upload icon and click on
  the ![](media/image3.jpeg){width="0.4236111111111111in"
  height="0.3541666666666667in"} Go button as displayed below:

![](media/image4.png){width="6.268055555555556in"
height="2.7090277777777776in"}

**Step 3**

Once the file is processed, it will ask you to save the zip file
(response). You can extract the zip file and open 4th excel file which
ends with Asset vantage MF CAMS.

![](media/image5.png){width="6.268055555555556in"
height="1.0333333333333334in"}

Process before you upload an excel file in AV system:

- Make sure PAN numbers are correct and mentioned against each
  transaction in the transaction file (entity name is not mandatory in
  this case).

- Add mutual fund ISIN code if it is captured as N.A. in excel file.

![](media/image6.png){width="6.268055555555556in"
height="0.8590277777777777in"}

- Remove transactions which are type of All other. However, make sure
  amounts, quantity and price columns are blank.

![](media/image7.png){width="6.268055555555556in"
height="0.8229166666666666in"}

**Step 4**

Process to upload an excel file in AV system:

- Go to **Menu **\> **Transactions **\> **Mutual Funds**.

- Go to upload tab.

- Keep entity drop down as Entity. Do no select any specific entity from
  list.

- Keep transaction type drop down same as default.

- Select file format as "AVMUTUALFUND" and date format as "DD MMM YYYY".

- Click on upload icon and select excel file from your folder.

![](media/image8.png){width="6.268055555555556in"
height="0.6520833333333333in"}

**Step 5**

Once the file is uploaded, system will show transactions in 3 colors as
mentioned below:

- Green colour: Error-free transactions.

- Orange colour: duplicate transactions.

- Red colour: transactions with error (e.g. incorrect entity name,
  incorrect scheme code, incorrect transactions type etc.).

![](media/image9.png){width="6.268055555555556in" height="2.7125in"}

If you see all transactions in green, you can select the checkbox and
click on process icon. If you see any transactions in orange with
message "duplicate transaction found", you can either delete the
duplicate transactions or if transactions are not duplicate than you can
process the same. if you see the transactions in red, you can either fix
the same from upload screen or you can reset the transactions you have
uploaded and fix the error in excel sheet and reupload the transaction
file.

![](media/image10.png){width="6.268055555555556in"
height="2.8222222222222224in"}

**Step 6**

Once the transactions are processed, it will disappear from upload
screen and it will show in respective entities in details tab.

![](media/image11.png){width="6.268055555555556in" height="2.59375in"}
