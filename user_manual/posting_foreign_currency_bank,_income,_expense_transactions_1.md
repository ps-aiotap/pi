Foreign Currency Bank and Cash Transactions

**Creation of Multi Currency Account**

Below are the steps to create multi currency accounts before entering
foreign currency Bank/Cash transfer:

**Step 1**

Go to **Menu **\> **Masters **\> **Accounts**. Create Asset : Bank
account "e.g. ABCD 778899" for the currency transfer
under **Menu **\> **Masters **\> **Accounts**.

![](media/image1.png){width="6.268055555555556in"
height="3.486111111111111in"}

**Step 2**

Create an Asset : Custodian account and select a corresponding Default
Payee / Payor Bank Account (as created in Step 1 above) for it.

![](media/image2.png){width="6.268055555555556in"
height="3.4791666666666665in"}

**Step 3**

Create two Expense Accounts; one for each currency. Please follow the
similar steps as shown in step 1 and 2.

![](media/image3.png){width="6.268055555555556in"
height="3.4930555555555554in"}

![](media/image4.png){width="6.268055555555556in"

**Post Transactions**

**Step 4**

Transaction entries involves the following steps:

a\. Enter a Withdrawal transaction in the bank account from where the
currency is being transferred/exchanged/sold.

b\. In the Ledger Account field, select the Expense account having the
same currency that we have created for the transfer (e.g. USD).

c\. Enter a Deposit transaction in the bank account wherein the currency
amount is being transferred to.

d\. In the Ledger Account field, select the Expense account having the
second currency (e.g. CAD).

Example: Transfer of USD 1,000 from ABCD Bank A/C# 778899 (USD account),
so that ABCD Bank A/C# 778899 (CAD account) will receive the amount of
CAD 1,200 (after conversion).

**Step 5**

Enter a Withdrawal transaction of USD 1,000 in USD account.

a\. Select the Bank account from which the money is being transferred.

b\. In the Ledger Account field, select the expense account created
earlier. In this example the Ledger account selected is ABCD Cross
Currency Expense Account.

c\. Update the amount which should be consistent with the account
currency e.g. USD 1,000.

![](media/image5.png){width="6.268055555555556in"
height="2.3826388888888888in"}

**Step 6**

Enter a Deposit transaction of CAD 1,200 in CAD bank account (where the
money is transferred to).

a\. Select the Bank account in which the money is being transferred to.

b\. In Ledger Account field, select the expense account created earlier.
In this example the Ledger account selected is ABCD Cross Currency Forex
Expense Account.

c\. Update the converted amount in CAD, which should be consistent with
the account currency e.g. CAD 1,200.

![](media/image6.png){width="6.268055555555556in"
height="2.379166666666667in"}

*Note**:** You will need to convert the USD to equivalent CAD manually
(using the actual conversion rate) and then use the respective amounts
while entering the transaction.*
