Document Management in AV ensures secure uploading and encrypting of
documents.

**User Access Permission**

To ensure privacy and control over who can manage documents within the
system, we offer customizable **User Access Profiles**. This allows you
to define specific permissions for adding, deleting, previewing, and
exporting documents across different modules.

Settings \> User Access Profile

In the **Module** section under \"Document\" access, there are four key
permissions:

- **Add**: Grants the ability to add documents from anywhere in the
  system, including the Document Vault.

- **Delete**: Allows the user to delete documents.

- **View**: Enables the user to preview documents.

- **Export**: Lets the user download documents.

**Note**: For users with an \'Admin\' role, the \"Export\" checkbox is
automatically checked. For other roles, it remains unchecked by default.
Existing users will have this checkbox checked only if they already had
\"View\" access for documents. 

**Attaching/ Previewing Document to Specific Entity/Group**

Menu Path: **Menu** \> **Masters **\> **Entity/Group**

**Step 1**

Either create an Entity/Group using the "+" in the top right-hand
corner, or click the edit symbol next to an existing Entity/Group.

**Step 2**

You will see the "Documents" field in the lower right-hand corner. Click
the "+" sign to attach a document to this specific Entity/Group. The
best practice is to title the document appropriately so that it is easy
to search. Then save your changes.

**Step 3**

After uploading, a "document folder" icon will appear. Clicking it will
open the "Document Preview" pop-up, where you can preview all uploaded
documents using the \"eye\" icon. You can also download documents if you
have the appropriate permissions.

**Attaching/ Previewing Document at Transaction Level**

Menu Path: **Menu \> Transactions**

**Step 1**

Either add a new transaction using the "+" symbol in the top right-hand
corner or edit an existing transaction using the edit symbol next to the
transaction.

**Step 2**

Under the "Documents" field, click on the "+" symbol to attach a
document to this transaction and 

click "Save."

**Step 3**

Once document is saved you will be redirected to the transaction screen
and you will observe, that now "document folder" icon is visible next to
edit and copy icon. And when you click on it "document preview\" pop-up
appears with list of all the documents attached to this Transaction. You
can preview each document by clicking on the "eye" icon 

You can also download existing documents from the transaction window by
clicking on the "Down Arrow" icon. 

(Please Note : Based on the access right defined for the User Profile,
the \'Download\' & \'Preview\' icons shall be disabled on the Document
Preview pop up screen.)

**Document Vault**

The Document Vault feature in AV allows you to access *all *your
documents in a single place. These include documents that you have added
at the entity/group level or transaction level or simply uploaded in the
document vault level.

Menu Path: **Menu **\> **Document Vault**

**Step 1**

Under the first drop-down box, navigate the Entity/Group for which you
want to view the documents. Click the check mark. Once the screen is
loaded you can preview each document by clicking on the "eye" icon.

(Please note : The Preview icon will be shown/disabled as per the
\'View\' access right given to the user)

 

**Step 2**

To download these files, click the checkbox next to the Entity/Group(s),
then click the \"Download" button.

**Step 3**

You can also attach a document to an existing Entity/Group through the
Document Vault. Click the "+" in the top right-hand corner, fill out the
following information then click the "Save" button.

**Viewing Documents on Wealth Register**

Menu Path: **Menu** \> **Analytics **\> **Wealth Register**

**Step 1**

Once the user processes from the filter and navigates all assets under a
specific Entity/Group, click on the specific investment. Notice a
"Documents" tab, here will house the documents attached to this fund. 

**Step 2**

The user has the option to Preview these documents by clicking on the
"eye" icon as well as option to download the document by clicking on the
file icon beside the file name.

**Step 3**

You also have the option to view documents in the "Transaction" tab.
Where at transaction level if any document is attached, you will be able
to identify it using the "document folder" icon present in the
1^st^ column to the left. When you click on it, the "document preview
pop-up" appears. Wherein you can view your attached document.

Please note: that this popup window is common across all reports under
Menu \> Analytics. Hence, you can access your documents from any other
Analytics report as well.
