**Position Master Search: Find What You Need, Instantly** 

Looking for a faster way to locate specific data in your Position Master
screen? The Position Master Search Functionality helps you filter and
find exactly what you need---quickly and efficiently. Follow this guide
for a smooth, time-saving navigation experience: 

**Step 1: How to navigate?**

- Go to **Menu **\> **Masters **\> **Positions **

**Step 2: Search by Column**

- Each column comes with its own independent search box, giving you
  precise control over your search.

- Entering text in a specific column filters the results only within
  that column---making your search faster and more targeted.

-  Example: If you type \"Apple\" in the Name column, you\'ll see only
  the rows where the name contains \"Apple\". It's a quick way to zoom
  in on exactly what you're looking for---no extra clicks needed. 

 

**Step 3: Combine Multiple Filters** 

- You can use multiple column search boxes at the same time to narrow
  down results even further.

- It's a powerful way to layer your filters and quickly zero in on the
  exact data you need.

- Example: Searching \"Apple\" in the Name column and \"Stock\" in the
  Asset Class column will show results that match both conditions. Use
  this to refine your view and focus only on the records that matter to
  you. 

 

**Step 4: Case-Insensitive Searches** 

- The search function is not case-sensitive---you'll get the same
  results whether you type \"apple\", \"Apple\", or \"APPLE\". 

<!-- -->

- That means less typing precision and more flexibility while
  searching.

- Example: Typing \"apple\" or \"Apple\" gives you the same results.
  It's designed to work intuitively, so you don't have to worry about
  capitalization. 

 

**Step 5: Handles Special Characters & Wildcard Searches** 

- The search function recognizes special characters like &, %, \$,
  and returns accurate results every time. 

<!-- -->

- You don't need to type the full word---just enter part of the text to
  get relevant matches instantly.

  like \"Apple Inc.\" Even partial matches help you get to the right
  data---fast and efficiently. 

**Step 6: Sorting and Filtering Together** 

- You can sort data and apply filters simultaneously for a more refined
  view.

- Example: First, sort the Name column alphabetically,
  then filter the Asset Class to \"Stock\"---a quick way to organize and
  target your results. 

 

**Step 7: Search Persistence** 

- Your filters stay in place even if you navigate between pages, sort
  columns, or refresh the screen. 

- If a search doesn't match anything, you'll simply see 'no results
  found'---so you always know where you stand.
