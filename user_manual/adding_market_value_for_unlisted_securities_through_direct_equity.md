Please follow below steps to add valuation transaction for unlisted
securities through Direct Equity module.

**Adding Valuation Transaction**

**Step 1**

- Go to **Menu **\> **Transactions **\> **Direct Equity**.

- Click on '**+**' sign.

![](media/image1.png){width="6.268055555555556in"
height="2.9194444444444443in"}

![](media/image2.png){width="6.268055555555556in"
height="0.7430555555555556in"}

**Step 2**

- Select Type as \"Unlisted\" and Transaction type as \"Valuation\".

- Add Market Price per share and save the transaction.

![](media/image3.png){width="6.268055555555556in"
height="2.6118055555555557in"}

**Multiple Valuation Transactions**

**Step 3**

You can add multiple valuations transactions for same securities. System
will always show the last valuation transaction price and date in
reports.

![](media/image4.png){width="6.268055555555556in"
height="1.6597222222222223in"}

Once you add the valuation transaction, you will see the last valuation
transaction price along with date in reports.
