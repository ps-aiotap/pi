A benchmark is a standard against which the performance of an Asset
class/Strategy/Advisor/Sector can be measured. In AV, the default
benchmark will be set to none, although it can be adjusted to align with
chosen benchmarks that reflect both your investment preferences and your
investment manager\'s strategy. 

**Finding Benchmarks **

Following are the steps to apply the Benchmark at Asset
Class/Strategy/Advisor/Sector level:\
Click on Menu \> Masters \> Benchmarks

![](media/image1.png){width="6.268055555555556in"
height="2.7534722222222223in"}

**Setting up Benchmarks**

**Step 1**

To set up the benchmark, Click on "+" icon available on right hand of
the screen.

![](media/image2.png){width="6.268055555555556in" height="0.8625in"}

**Step 2**

If you want to add benchmark at group level, select group from list. If
you want to add benchmark at individual entity level, you have to choose
specific entity from list.

![](media/image3.png){width="6.268055555555556in"
height="3.748611111111111in"}

**Step 3**

Once you select the Entity/Group, you must select grouping for which you
want to setup benchmark.

![](media/image4.png){width="6.268055555555556in"
height="3.7888888888888888in"}

**Step 4**

Once you select Asset Class/Strategy/Advisor/Sector, you will see
respective groups in list below. You can now choose the benchmark from
user defined benchmark column. By default, you will see Nifty 50 or S&P
500 TR as by default benchmark setup. However, you can select any other
benchmark from the dropdown list.

![](media/image5.png){width="6.268055555555556in"
height="3.786111111111111in"}

**Step 5**

Select effective date & click on save. From this date, benchmark will
get applicable to your portfolio grouping level.

![](media/image6.png){width="6.268055555555556in"
height="2.5194444444444444in"}

**Step 7**

Once you setup the benchmarks from master, follow below steps to process
reports (PPS and MPPR)

1\. Go to Menu \> Analytics \> Portfolio Performance report, make sure
you have selected \'PME benchmark\' option from show columns.

![](media/image7.png){width="4.118055555555555in"
height="5.631944444444445in"}

![](media/image8.png){width="6.268055555555556in"
height="1.9513888888888888in"}

2\. Go to Menu \> Analytics \> Multi-Period Performance Report and make
sure you have selected \'Benchmark\' from show columns.

![](media/image9.png){width="3.8402777777777777in"
height="5.479166666666667in"}

![](media/image10.png){width="6.268055555555556in"
height="1.8118055555555554in"}

 

**Notes:**

In case user doesn\'t want to tag any Benchmark then user can select
\'None\' from dropdown values. With \'None\' option Benchmark TWR and
PME Benchmark IRR will not be computed at position or at grouping
levels.
