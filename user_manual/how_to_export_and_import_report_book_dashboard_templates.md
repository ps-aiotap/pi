If you regularly work with dashboards, especially across multiple
systems, you'll know how much time it can take to replicate settings,
widgets, and configurations. With AV's enhanced functionality, that
hassle is now a thing of the past. 

Power users can now export and import dashboard templates across
different systems---or even within the same system. This feature saves
time, eliminates repetitive manual work, and ensures consistency,
especially for multi-client family offices managing several systems
simultaneously. 

Let's dive into how you can make the most of this feature. 

**Exporting a Dashboard Template** 

Exporting a dashboard template is straightforward and ensures you
capture all widgets and their specific configurations. Here's how to do
it: 

**Step 1 : Navigate to Report Book **

- Go to Menu \> Report Book. 

<!-- -->

- On the left sidebar, you'll see a list of dashboard names. 

<!-- -->

- Select the dashboard template you want to export. 

<!-- -->

- Wait for all widgets to fully load and display their data. 

<!-- -->

- Double-check the loaded screen to ensure that everything looks the way
  you want it before proceeding. 

**Step 2 : Export the Dashboard **

- Look for the "Export Dashboard" icon on the right side of the
  dashboard name. 

<!-- -->

- Click this icon to download a JSON file. This file contains all your
  dashboard information, including widgets, layout, and configurations. 

 

You've now successfully exported your dashboard template! If you want to
replicate this dashboard in a different system or include it in a report
book, you can easily do so by following the import steps below. 

**Importing a Dashboard Template** 

Now that your dashboard template is exported, here's how you can import
it into the same system or a new one:

**Step 1** 

- Click the '+' icon to add a new dashboard. 

<!-- -->

- A pop-up window labelled "Add Dashboard" will appear. 

**Step 2** 

- In the pop-up window, under the 'General' tab, locate the \"Import
  template\" field at the top. You'll see a folder icon next to it. 

<!-- -->

- Click on this field to open your file explorer. 

** **

**Step 3** 

Select the previously exported JSON file that you want to import. Please
note that only JSON files are supported; if you try to upload any other
file format, an error message will appear. Once selected, the pop-up
will close, and the fields will automatically populate with the imported
dashboard's information. 

- The \"Import template\" field will display the name of the imported
  dashboard and its JSON file name. 

<!-- -->

- The \"Dashboard name\" field will default to \"New Dashboard\_\" with
  a timestamp, but you can rename it as you like. 

<!-- -->

- You can also update other fields just like you would when creating a
  new dashboard from scratch. 

Once you've made the necessary changes, click 'Save'. 

**Step 4** 

- After saving, the pop-up will close, and your new dashboard template
  will appear in the left sidebar under your list of dashboard names. 

<!-- -->

- Open the new dashboard and give it some time to load. 

<!-- -->

- The system will display the dashboard using the same visuals and
  widget settings as your exported template, automatically loading data
  for the default entity you\'ve selected. 

*Note on Widget Access *

*If you export a dashboard from a system where you have access to all
widgets and import it into another system with restricted access to a
few widgets, the uploaded dashboard will only display the widgets you're
allowed to access in the new system. *
