AV now supports maintaing master and valuation for Derivatives through
feeds.

**Understanding functionality**

Derivatives listed master functionality ensures hassle free creation of
listed master without taking extra step of creating it manually. It auto
creates listed master while entering/ uploading transaction in the
system. Such listed master will be priced daily through feeds there by
reducing manual efforts of user to enter valuations.

Auto master creation functionality will automatically create derivatives
master by making use of Code and user doesn't have to wait to enter
transaction due to unavailability of master. This functionality will
help user to create listed derivatives viz options and futures for only
INR currency.

**Entering Derivative Transactions**

 Go to **Menu **\> **Transactions **\> **Derivatives**.

- User must enter a **code** on derivatives add/ edit screen or in
  transactions uploads file in field/ column 'Instrument Name' or 'Code'
  respectively.
