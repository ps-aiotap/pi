The Income Statement Variance Widget enables you to analyze and compare
financial performance across different time periods, providing both the
amount and percentage variance between income and expense figures. This
guide walks you through how to access, configure, and interpret the
widget on desktop and mobile.

**Step 1 : What Does the Widget Do?**

The Income Statement Variance Widget:

- Performs variance analysis between selected periods for Income and
  Expense accounts.

- Displays both absolute (amount) and relative (percentage) variance
  values.

- Allows complete customization of comparison periods Monthly,
  Quarterly, Yearly, or Year-to-Date (YTD).

- Enables multi-entity and group-based analysis for consolidated or
  segmented reporting. 

                           

**Step 2 : Accessing the Widget     **

                     ![](media/image1.png){width="5.1875in"
height="4.506944444444445in"}

1.  Navigate to the Report Book.

2.  Go to Add Widget and select General Ledger Widget.

**Step 3 : Configuring Your Report : Apply Filters  **

       

       ![](media/image2.png){width="5.104166666666667in"
height="5.756944444444445in"}

1.  Report Type:

    - Income Statement

    - Report Mode: Sequential

2.  Entity, Template & Grouping:

    - Select the entity or entities and group for which you want to
      perform variance analysis.

3.  Period Settings:

    - Select the comparison frequency Monthly, Quarterly, Yearly, or
      Year-to-Date (YTD).

    - Choose the number of periods (1--12).

    - Set your "As On" period and the period to compare against.

4.  Other Fields:

    - Select the Show Variance, Variance Percentage & Summary.

**Step 4 : Understanding the Variance Logic**

- The widget compares Income and Expense accounts between the two
  selected periods.

- Displays both:\
    Variance Amount = Current Period -- Comparison Period\
    Variance Percentage = (Variance ÷ Comparison Period) × 100

- Supports analysis for both individual entities and group
  consolidations.

**Step 5 : Viewing the Results**\
    ![](media/image3.png){width="6.268055555555556in"
height="2.341666666666667in"}

Once processed, the widget displays results in a tabular view with clear
breakdowns of:

- Income and Expense line items.

- Amount variance between selected periods.

- Percentage variance for each account.

- Totals and subtotals for quick summary interpretation.
