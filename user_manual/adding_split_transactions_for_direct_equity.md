**What is Stock Split ?**

A stock split is a corporate action where a company increases the number
of shares by reducing the face value of the stock.

In the system, split transaction for both listed as well as unlisted
equity needs to be added manually. The below steps explain how to add a
split transaction for stocks through direct equity module.

**Enter Split Transaction** 

Following are steps that will help you to pass stock split transactions
for equities in your AV system.

**Step 1**

Go to \'Menu,\' then \'Transactions,\' and finally, \'Direct Equity\'.
Then, click on the \'+\' sign to add a new split transaction.

![](media/image1.jpeg){width="6.268055555555556in"
height="2.2444444444444445in"}

**Step 2**

In the pop-up dialogue box that opens, select the relevant details for
all the dropdowns (like \'Type,\' \'Entity, etc.).

- Record Date: Date from when the company announces the stock split.
  This is usually two days after the \'Ex Date\'.

- Ex Date: Date for when the stock split occurs.

- Security Name: Security for which Split Transaction to be posted.

- Split Ratio: Given by the company announcing the stock split.

Click on the save at the top right corner of the dialogue box to save
transaction.

![](media/image2.jpeg){width="6.268055555555556in"
height="3.4451388888888888in"}

*Note: User can round off (round up or round down) the number of shares
which are resulted after the split.*

**Step 3**

User can now see newly posted split transaction on the transaction
screen.

![](media/image3.jpeg){width="6.268055555555556in"
height="1.3645833333333333in"}
