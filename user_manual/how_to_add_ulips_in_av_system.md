Please follow below steps to add transactions for ULIP (Unit Linked
Insurance Plan) through Unitized Fund module.

**Setting up Insurance Master & Payor Account**

**Step 1**

**Insurance Master Setup**

- Go to **Menu **\> **Masters **\> **Unitized Fund**.

- Click on '**+**' sign \> add Fund House Name (name of the Insurance
  Company) \> add Fund Name (name of ULIP scheme).

- Select Currency and click on save.

![](media/image1.png){width="6.268055555555556in"
height="2.4180555555555556in"}

**Step 2**

**Payor/Custodian Account Setup**

- Go to **Menu **\> **Masters **\> **Accounts**.

- Click on '**+**' sign \> Create Payor (Insurance Broker).

![](media/image2.png){width="6.268055555555556in"
height="2.654166666666667in"}

- Custody (Account for Insurance Policy number).

![](media/image3.png){width="6.268055555555556in"
height="2.8805555555555555in"}

**Adding Transactions**

**Step 3**

- Go to **Menu **\> **Transactions **\> **Unitized Fund**.

- Click on '**+**' sign.

![](media/image4.png){width="6.268055555555556in"
height="2.5430555555555556in"}

**Step 4**

**Premium Transaction Entry**

- Select Entity and Transaction type as Contribution to show premium
  paid.

- Select the Custody account for which you want to post premium
  transaction.

- Add transaction date, select Security name and enter quantity & price.

- Click on save.

![](media/image5.png){width="6.268055555555556in"
height="3.7118055555555554in"}

**Step 5**

**Valuation Entry:** You can add latest NAV of ULIP using valuation as
transaction type.

![](media/image6.png){width="6.268055555555556in" height="2.55625in"}

 **Step 6**

**Report View: **You can view the holding using Wealth Register report
under Analytics.

![](media/image7.png){width="6.268055555555556in"
height="1.2048611111111112in"}
