**Introduction:** 

Asset Vantage allows you to bookmark your preferred dashboards within
the Report Book for quick and easy access every time you login. This
feature ensures that you can immediately access your most-used reports
and dashboards, without navigating to create your starred dashboards
multiple times.

**STEP 1: How to navigate Bookmark on Report Book?** 

- Go to **Menu \> Report Book**

- Drag and drop different widgets to create a dashboard. 

![Picture](media/image3.png){width="6.268055555555556in"

- Unlock the dashboard ![Picture 1,
  Picture](media/image4.png){width="0.4236111111111111in"
  height="0.3680555555555556in"} and locate the bookmark icon on the
  toolbar (left icon to Report Book Group).  

![Picture](media/image5.png){width="6.268055555555556in"
height="3.076388888888889in"}    

**STEP 2: Bookmarking a Dashboard:** 

- When you click on the Bookmark icon, it will save the current
  dashboard as your default (i.e., bookmarked) dashboard for future
  use. 

<!-- -->

- If you already have a dashboard bookmarked (for example, Dashboard A)
  and you select a new one (like Dashboard B), clicking on the Bookmark
  icon will overwrite the previous bookmark, setting Dashboard B as your
  new default dashboard. 

![Picture](media/image6.png){width="6.268055555555556in"
height="3.076388888888889in"}   

**STEP 3: Confirm Bookmarking:** 

- Once you click the **Bookmark icon**, a **pop-up confirmation** will
  appear: You can click 'OK' or 'Cancel' 

![Picture](media/image7.png){width="6.268055555555556in"
height="3.076388888888889in"}    

**STEP 4: Visual Confirmation:** 

- After bookmarking, the **Bookmark icon** will turn **orange** (or
  according to the color theme of your system) to visually confirm the
  action. 

<!-- -->

- The icon will remain available on the **toolbar **above, allowing you
  to access it at any time, regardless of whether the report book is
  locked or not. 

![Picture](media/image8.png){width="6.268055555555556in"
height="3.076388888888889in"}    

** STEP 5: Removing a Bookmark:** 

- If you click the **Bookmark icon** when a dashboard is already
  bookmarked, it will **remove** the bookmark and revert to the default
  settings (i.e., without a bookmarked dashboard). 

![Picture](media/image9.png){width="6.268055555555556in"
height="3.076388888888889in"}

**STEP 6: Set a Default Dashboard:** 

- Go to **Menu **\> **Settings **\> **User **\> **User Dashboard
  Access**.  

![Picture](media/image10.png){width="6.268055555555556in"
height="3.076388888888889in"}  

- You will see an option of 'Set Bookmark' below the 'Delete' button. 

<!-- -->

- Select a dashboard from the 'Selected Dashboards' list and click
  'Set Bookmark' to mark it as your default dashboard.  

![Picture 1630323285,
Picture](media/image11.png){width="1.5277777777777777in"
height="0.3263888888888889in"}     

![Picture](media/image12.png){width="6.268055555555556in"
height="3.076388888888889in"}   

***Note: **You can only have **one default dashboard** at a time. If you
try to set another dashboard as default, it will replace the current
default. *

![Shape](media/image13.png){width="6.944444444444444e-3in"
height="6.944444444444444e-3in"} 

**    STEP 8: Displaying Bookmarked Dashboards:** 

- Any dashboard you bookmark from the **Report Book screen** will
  display the **bookmark icon** next to its name in the **User Dashboard
  Access** section. 

<!-- -->

- This helps to quickly identify which dashboard is set as
  the **default** and ensures you can access it easily in the future. 

<!-- -->

- This action will work both ways --- from the **Report Book
  screen** and the **User Dashboard Access** page. 

 

**Conclusion:** The bookmarking feature in Asset Vantage significantly
enhances user experience by providing quick access to preferred
dashboards. This improvement not only saves time but also ensures
smoother and more efficient navigation throughout the platform.
