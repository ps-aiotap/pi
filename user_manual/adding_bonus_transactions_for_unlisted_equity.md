**Enter Bonus transaction**

The below steps explain how to add bonus transactions for unlisted
equity on the AV system.

**Step 1**

Go to \'Menu,\' then \'Transactions,\' and finally, \'Direct Equity\'.
Then, click on the \'+\' sign to add a new bonus transaction.

![Menu Transaction Direct
Equity](media/image1.jpeg){width="6.268055555555556in"
height="2.2354166666666666in"}

**Step 2**

 In the pop-up dialogue box that opens, select the relevant details for
all the dropdowns. For example,

- Type: Always select \'Unlisted\' for this type of transaction.

- Transaction Type: Select \'Bonus\'.

- Security Name: Security for which you want to post the bonus
  transaction.

Fill in all other details like the \'Record Date,\' \'Ex Date,\' and
\'Bonus Ratio\'. Finally, click on the save at the top right corner of
the dialogue box to save transaction.

![](media/image2.jpeg){width="6.268055555555556in"
height="3.4631944444444445in"}

*Note: User can round off (round up or round down) the number of shares
which are resulted after the bonus.*

**Step 3**

User can now see newly posted split transaction on the transaction
screen. And system will consider zero cost of acquisition for bonus
holdings for gain/loss calculations.

![](media/image3.jpeg){width="6.268055555555556in"
height="1.2541666666666667in"}
