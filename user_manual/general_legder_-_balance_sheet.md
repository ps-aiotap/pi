**About the Balance Sheet**

A balance sheet is one of the key fundamental financial statements that
provides a snapshot of an entity's/group's financial condition as on a
particular date. It summarizes an entity's total assets and how such
assets are financed, whether through equity or debt (Assets = Equity +
Liability). It is typically issued at the end of the financial reporting
period.

**Generating the Balance Sheet**

**Setting  a Template**

**Step 2 **

Before you dive into generating a balance sheet, let\'s set a template
for it. Use our predefined templates - US GAAP and IFRS. Or, you can
configure a custom template from the 'Chart of Accounts'. Go to 'Menu',
'Masters', then to 'Chart of Accounts'. Learn how to set up and
customize the Chart of Accounts with [this
article](https://support.assetvantage.com/hc/en-us/articles/360018745738-Setting-up-and-customizing-chart-of-accounts-COA-using-the-base-GAAP-and-IFRS-templates).

** Selecting report filters**

**Step 3 **

Select the appropriate filters to run the balance sheet:

![](media/image3.png){width="6.268055555555556in"
height="3.467361111111111in"}

- 

**Entity / Group:** Reports can be run for an individual entity or a
group of entities for consolidated reports, using the Entity / Group
filter.

- 

**Template:** This dropdown has the predefined US GAAP and IFRS
templates, and will also reflect any custom template defined for the
selected entity. The default template selected on the entity master will
be selected by default here too.

- 

**As of Date:** You can run this report as on a particular date using
the \"As of\" date filter.

- 

**Basis:** You can view the balance sheet by cost basis or valuation or
both.

Note: The default selection is 'Cost & Valuation'. 

**Exporting the Balance Sheet**

**Step 4 **

Your processed report can now be downloaded in Excel or PDF format.

![](media/image4.png){width="6.268055555555556in"
height="3.0395833333333333in"}

Note: Please ensure that the balance sheet is balanced the first time as
of the entity's book start date, i.e., Assets should be equal to
Liabilities + Equity. The system creates double sided journal entries
for all transactions after the book start date, to ensure that the
balance sheet is always balanced.
