We've introduced the \"User Login Details\" feature in the Gateway menu
to help the Customer Success (CS) team proactively track user
activity, identify engagement patterns, and anticipate license renewal
probabilities. This feature enables better client communication and
data-driven decision-making. 

**How to Access the \"User Login Details\" Feature** 

CS team members with license creation access can find the \"User Login
Details\" feature in the Gateway menu, located just below the \"Unblock
User\" option in these gateways: 

- Live Gateway 

<!-- -->

- India Gateway 

<!-- -->

- Singapore Gateway 

**How This Feature Supports the CS Team** 

With this feature, the CS team can: 

- **Track System Login Frequency** -- Monitor how often users log into
  the system during the license period. 

- **Identify Active & Inactive Users **-- Find out which user IDs are
  frequently used and which ones are underutilized.

- **Predict License Renewals** -- Use login frequency to anticipate the
  likelihood of a license renewal.

**How to Use the \"User Login Details\" Feature** 

Follow these simple steps to access and analyze user login details: 

- **Navigate to the Gateway Menu -- **Select "User Login Details"
  feature from the menu. 

<!-- -->

- **Apply the Date Filter -- **In the top-right corner, you\'ll find a
  filtering option labelled "As on date". 

<!-- -->

- **Select a Specific Date** -- Choose a date from the drop-down menu.
  This will display login data for the preceding 12 months, including
  the selected month. 

\-* **Example:*** If you select January 8, 2024, the system will display
login data from February 1, 2023, to January 8, 2024. 

- **Export the Data** -- Download the login details in Excel format for
  further analysis. 

**Understanding the Exported Data Format** 

When you export the login details, the Excel file will include key
information to help you analyze user activity
effectively. Here's what you'll find in the exported file: 

  -----------------------------------------------------------------------
  **System Name**                     The name of the client's system 
  ----------------------------------- -----------------------------------
  **Display Name**                    The user's profile name. (Note:
                                      Internal users with emails ending
                                      in *\@assetvantage.com* are
                                      excluded.) 

  **Email**                           The user's registered email
                                      address 

  **System URL**                      The unique URL for the client's
                                      system 

  **Last Login**                      The most recent login timestamp
                                      in **DD/MMM/YYYY HH:MM** format 

  **Count of Logins**                 The total number of times the user
                                      has logged in within the selected
                                      12-month period. 
  -----------------------------------------------------------------------

 

***Important Note About "Count of Logins" ***

*The "Count of Logins" reflects every login instance. So, if a user logs
in five times in a single day, all five logins are counted in the
total. *
