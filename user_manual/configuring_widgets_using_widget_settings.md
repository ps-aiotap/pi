**All about widget settings **

Configure your widgets using this handy \'widget settings\' guide.
Explore common settings like Refresh, Filter, Column Sorting, and more,
to customize any number of widgets in your dashboard(s). 

**How to configure widgets **

**Step 1 **

In the 'Report Book', clicking 'Add Widget' in any dashboard will add a
new widget, which you can configure using the below settings.

*Tip: Learn about report books and configuring them from our \'[Creating
AV report
book](https://support.assetvantage.com/hc/en-us/articles/4403260437393-Creating-AV-report-book)\' article.*

**Step 2 **

Most widgets include the following settings:

![](media/image2.gif){width="6.268055555555556in"
height="3.5256944444444445in"}

- **Edit Dashboard:**  Click this to open a pop-up window that lets you
  change data as needed. 

- **Editable Widget Name:** Change the name of your chosen widget. 

- **Expand All:** Expand all the levels.

- **Collapse All:** Collapse all the expanded levels.

- **Expand Dropdown:** Dropdown values signify the level of rows to
  expand; you can select from the range of levels - Level 1, Level 2,
  Level 3 and even Custom to expand in the widget, and then save your
  changes.

![](media/image3.gif){width="6.268055555555556in"
height="3.5256944444444445in"}

*Note: Data in the CSV extract will reflect the number of rows/levels
selected in the 'Expand Dropdown'. *

- **3 Dots Icon: **The 3 Dots icon consists of the various options for
  Table & Chart type:

- **Export in CSV:** This allows you to export data in CSV format.\
  *Note: Data in the CSV extract will reflect the number of rows/levels
  selected in the 'Expand Dropdown'.*\
  *\*

- **Export in Excel:** This allows you to export data via Excel.\
  *Note: Data in the Excel extract will reflect the number of
  rows/levels selected in the 'Expand Dropdown'. *

- **Restore default sorting:** This restores the sorting of the report
  back to the default sorting defined in the system.

- **Show Currency Symbol:** This allows you to see data with its
  currency symbol.

- **Show Footer Notes:** This allows you to see notes related to the
  report at the bottom of the widget.

- **Show Chart Label:** This allows you to see the chart label on your
  chart report. This is applicable only for chart type reports.

- **Show Data Labels:** This allows you to see the labels of the data or
  the data values on the chart. For Multiple period widget you have
  option to see data Labels for the Open High Low Close, All and Only
  for Close values.

- **Show Legend:** This allows you to see the data legend for the chart.
  You have further option to display the legend at the Bottom, Left and
  Right of the widget.

- **Column Sorting:** Sort the column in ascending/descending order.

- **Column Width Scroll Bar:** Adjust the width of the first column.

- **Filter:** Select the filter combination for various existing report
  types. Here, the \'Summary\' checkbox lets you hide position-level
  data if it is checked, while the \'Select All\' checkbox automatically
  considers a newly added position, strategy, asset class, account,
  currency, etc., whether you are processing this automatically or
  manually. Learn more about position tags, and custom position tags,
  here.\
  \
  *Note: You\'ll need to individually select the \'Summary\' checkbox
  inside each widget filter for existing widgets to get this setting, as
  these always retain their previous preferences.* \
  **\**

- **Refresh:** Refresh existing data without processing the filter, if
  you've changed the chart type or size of the widget.

- **Copy Widget:** Copy the widget with data on the current dashboard.

- **Remove Widget:** Delete the widget.

*Tip: The only way to view these widget settings? Hover your mouse over
the icons.*

**Step 3 **\
\
Click 'Process' to see your widgets with configured data.\
