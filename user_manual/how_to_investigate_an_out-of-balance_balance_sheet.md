*Is your balance sheet out of balance? Follow the steps below to
investigate the issue.*

**Run Balance Sheet on the day before "book start date"**

**Step 1 **

If you see that your balance sheet is out of balance, step one is to
check the balance sheet on the day before the book start date.

Tip:  You can find the "book start date" of an entity by going to
"Masters" and then to "Entity/ Group".

![](media/image1.jpeg){width="6.268055555555556in" height="1.4875in"}

- If you find that the balance sheet is out of balance on the day before
  the book start date, it is likely that an entry was made prior to the
  book start date.  You would then need to determine if that entry was
  correct or not.  If it is not correct you should move the entry to the
  correct date. 

- If the entry is correct you need to adjust the opening balance of an
  offsetting account such as Owners Equity, Retained Earnings, Partner's
  Capital, etc., to re-balance the account. This will be done in Masters
  \> Accounts.

![](media/image2.jpeg){width="6.268055555555556in"
height="3.5256944444444445in"}**Check Voucher Audit Report\**

- If the balance sheet goes out of balance after the book start date,
  then check for an incorrect voucher entry. To do this you should run
  the Voucher Audit Report.

- In Asset Vantage go to Menu \> General Ledger  \> Voucher
  Audit. *Learn more about the [\"Voucher Audit
  Report\"](https://support.assetvantage.com/hc/en-us/articles/5786883790481-Voucher-Audit-Report) here.*

- Run the report for the entity and select Modules: "All"; Account Type:
  "All"; Accounts: "All".

- "From date" should be the day after the Book Start Date. The "To Date"
  would be the current date or the date that the report is first out of
  balance.

- In the Report Filter, select "Show only mismatched entries" "Show with
  blank account number" and "Show with no vouchers" checkboxes.

![](media/image3.jpeg){width="6.268055555555556in"
height="2.6118055555555557in"}

- Once the report has populated it will show you the transaction(s) that
  is causing the balance sheet to be out of balance.

Tip:  Usually, if you go into the entry and Edit\\Save the transaction,
the system will correct the entry.
