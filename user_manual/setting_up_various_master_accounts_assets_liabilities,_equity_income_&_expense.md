**Accounts : Manual Entry**

The "Master" module is a one stop point for creating and maintaining
universal accounts within your system which will be refenced, tagged and
used throughout your system while uploading transactions and viewing
analytical reports.

- Go to Menu \> Masters \> Accounts \> "+" Sign to Manually Add accounts

- As discussed in the beginning of this handbook, you can either
  manually add or directly upload in bulk

- The "Class : Account Type" defines the various Account types which can
  be selected in the AV system. They are namely :

- - Asset : Custodian (for Mutual Funds folios, Direct Equity D, Managed
    Accounts etc

  - Asset : Bank (for bank accounts)

  - Asset : Ledger (for creation of various custom ledger accounts on
    the asset side)

  - Asset : Payor (for brokers and payor accounts)

  - Liability : Bank (for Credit card,  etc)

  - Liability : Loan (Loan accounts)

  - Liability : Ledger

  - Liability : Payee

  - Income : Income Account (salary Account, etc)

  - Expense : Expense Account (Wages, Etc)

  - Equity : Ledger

**Asset : Custodian**

Class : Account type -- Asset : Custodian lets you create masters for
all AMC, custodian, Mutual Funds, Direct Equity, Managed accounts, hedge
funds, unitized funds etc

- Select Asset : Custodian in the "Class : Account type" field

- Select the entity for which you want to create the account

- Enter the Account name and number along with the currency

- In the "For" field you can enter for which type you want to create
  this account. Eg: AMC account, brokerage etc

- You can also assign a custom short code to identify this account while
  entering transactions. Just type the short code and select

- Display name is a concatenated version of all the fields entered
  above. This gives a clear and crisp display feature in generating
  reports and transaction views

- 'Capitalize Expenses' checkbox  will capitalizes your expenses (like
  Brokerage, Stamp Duty & Other charges) except STT for Direct Equity &
  Mutual Funds transactions only through uploads.

- Select the default Payee/Payor account (covered in the following
  pages) which will be attached to this custodian account

Enter the 2nd, 3rd holder, Nominee, Tax code, Tax Section, payment date,
sync accounts (for US customers only) and attach an address to it

**Asset : Bank**

Class : Account type -- Asset : Bank lets you create masters for all you
bank accounts. You can also enter the opening balances for each account

- Select Asset : Bank in the "Class : Account type" field

- Select the entity for which you want to create the account

- Enter the Account name and number along with the currency

- In the "For" field you can enter for which type you want to create
  this account. Eg: Bank, AMC account, brokerage etc

- You can also assign a custom short code to identify this account while
  entering transactions. Just type the short code and select

- Display name is a concatenated version of all the fields entered
  above. This gives a clear and crisp display feature in generating
  reports and transaction views. This automatically gets updated

- Notice a couple of fields have been disabled. Print Checks option lets
  you print physical checks through this account. Check this to activate
  check print feature.

- You have an option to fill the Opening balance. This field is helpful
  in entering the opening balance if you want to enter the transactions
  before book start date.

- Default payee/payor bank account fields is disabled because you cannot
  have those for a bank account

- Enter Tax code, Tax Section, payment date, sync accounts (for US
  customers only) and attach an address to it

- Default Transaction Status let you set up default status for your
  Deposit and Withdrawal transactions.

**Accounts : Bulk Upload**

![](media/image10.png){width="6.268055555555556in"
height="2.252083333333333in"}

- Alternative to Manual entry, is an option to upload all your accounts
  in one go

- Go to Menu \> Masters \> Uploads *(Which is one of the tabs on the top
  right corner)*

- Download the AV format which is an excel file and feed in all your
  accounts based on the Account types. You can upload multiple account
  types. See the sample screen shot of the Excel file

- After you have saved the excel file, head back to your AV system and
  upload it by clicking Upload

![](media/image11.png){width="6.268055555555556in" height="0.8375in"}

![](media/image12.png){width="6.268055555555556in"
height="1.0277777777777777in"}

- All the entries will be listed down on the screen. The rows in "Green"
  indicate correctly uploaded entries, The ones in "Pink" are errors
  (with indication on the reason for error).

- You can directly fix these by clicking on "Edit"

- An account Add/Edit dialogue box will open where you can fix the
  errors. Check all the mandatory fields *(Marked with a yellow
  horizontal line)*  to see if any fields are incorrectly filled or are
  empty.

- After all the rows are "green", you have to select all of them by
  clicking on the "Check box" and then hit "Process"

- You can then view all the uploaded entries in the "Details" tab right
  beside the "Uploads" Tab. Just Click on
