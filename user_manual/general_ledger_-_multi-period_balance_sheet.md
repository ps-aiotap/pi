**About the Multi-period Balance Sheet**

The multi-period balance sheet is a report that summarizes an entity\'s
assets, liabilities, and equity over multiple time periods. It is the
time series analysis of balance sheet in a single screen. You can select
the frequency and number of periods from a start date to analyze the
data.

**Finding the Multi-period Balance Sheet**

**Step 1 **

Go to the multi-period balance sheet by going to 'Menu', then 'General
Ledger', and finally, 'Multi-Period balance sheet'.

**Generating Multi-Period Balance Sheet**

**Selecting Report filters**

**Step 2 **

On the top right corner of this page is a 'filter' option. You need to
check and select filters as per your requirements before generating the
multi-period balance sheet.

![](media/image2.gif){width="6.268055555555556in"
height="3.5256944444444445in"}

- **Template:** The template dropdown has two predefined templates - US
  GAAP and IFRS. However, if users need to configure custom templates,
  they can do so by going into 'Masters' from the 'Menu,' and then
  selecting 'Chart of Accounts'.\
  *For detailed information about this process, please refer to [this
  article](https://support.assetvantage.com/hc/en-us/articles/360018745738-Setting-up-and-customizing-chart-of-accounts-COA-using-the-base-GAAP-and-IFRS-templates).*

- **'Period\' and 'Number of Periods':** You can select monthly,
  quarterly or yearly frequencies along with the number of periods,
  going up to 12. For instance, if you wish to run a quarterly report
  for the calendar year 2021, you'll need to select Period as
  \'quarterly,\' the Number of Periods as \'4\', and the starting month
  and year as January 2021.

- **'Cost Basis' and 'Valuation':** You also have the option to run this
  report based on either cost basis or valuation at a time.

- **Process:** After selecting filters as needed, click 'Process' to run
  your report.

**Exporting the Multi-Period Balance Sheet**

**Step 3 **
