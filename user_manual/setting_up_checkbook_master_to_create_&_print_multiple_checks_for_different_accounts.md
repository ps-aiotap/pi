The checkbook master helps you create and manage multiple checkbooks for
different accounts. This is mandatory if you want to print checks
through an account.

**Configuring a Checkbook**

- Go to **Menu** **\>** **Masters** **\>** **Checkbook**.

- You can see the list of existing checkbooks by entity by selecting the
  entity and hitting on Go. 

- To create the checkbook, click on the "**+**" sign on the top right
  corner. 

![](media/image1.png){width="6.268055555555556in" height="1.33125in"}

- A checkbook Add/Edit dialogue box will open. 

- Select the entity for which you want to create the checkbook. 

- Choose the account for which you want to create the checkbook for.\
  \
  *Note: To activate this check, recollect checking the "Print checks"
  option in the master creation step*\
  *\[Ref: Asset : Bank Module\].*

<!-- -->

- Enter a Nick name (user defined) to identify the checkbook. 

- Enter the series of the checkbook. If you exhaust the series, system
  will automatically take the next running series. 

- Enter the Account Number for which this checkbook is being created.
  Same as "account -- For" field. 

- The bank routing number is the one through which you want to route
  this check. 

- Select from our list of Templates, which best suits your current
  checkbook format. 

- Select the address of the bank. You can add new address by Menu \>
  Masters \> Address. 

- You have an option to upload a sample check for reference purposes. 

- Go ahead and hit on "Save" after you have completed. 

- This newly added checkbook can be viewed on the same window by hitting
  on "Go".
