A Consolidating Income statement presents incomes and expenditures of
entities belonging to a group (as defined by the User) for a given
period in a single viewing window. The entity-wise profit or loss is
determined by taking all revenues and subtracting all expenses from both
operating and non-operating activities.

**Finding Consolidated Income Statement**

Navigate to the Consolidating Income Statement by going to 'Menu', then
'General Ledger', and finally, ' Consolidating Income Statement'.

**Generating Consolidating Income Statement**

**Selecting Report filters**

- User needs to select appropriate filters to generate the Consolidating
  Income Statement for the selected group.

- Template dropdown has predefined US GAAP and IFRS template and will
  also reflect any custom template defined by the user for the selected
  group. Default template selected on group master will be selected by
  default.

- Report period dropdown enlists all the financial years since
  inception. User may also run this report for custom dates by selecting
  the From and To Date.

**Setting Template**

Before you dive into generating a consolidating Income Statement, let\'s
set the template for it.There are predefined templates (US GAAP and
IFRS) readily available for an entity/ group but if user wants to
configure custom template, then it can be done from Chart of Accounts
(path: Menu \> Masters \> Chart of Accounts). Please refer [this
article](https://support.assetvantage.com/hc/en-us/articles/360018745738-Setting-up-and-customizing-chart-of-accounts-COA-using-the-base-GAAP-and-IFRS-templates).
