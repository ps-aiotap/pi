**Understanding corporate actions**

Corporate actions that need to be processed include Dividend Payout,
Bonus and Splits.

*Note: Processing of corporate actions will only be possible if
transactions are entered and positions are available in the system. *

**Finding corporate actions in the AV system**

**Step 1 **

Go to 'Menu', 'Transactions', then head to 'Corporate Actions'.

![](media/image1.gif){width="6.268055555555556in"
height="3.3305555555555557in"}

**Running Corporate Actions for Single or Multiple Entities/Groups**

You can process corporate actions for single or multiple holdings
simultaneously for All Entities & Groups.

Utilize the filter options on the corporate actions screen to refine
your data by Account, Holding Name, and Date Range. You can set the TDS
percentage to automatically compute TDS on Dividends.

**Step 2 **

 Select the entity or group for which you want to run the corporate
actions.

 

The second filter is set to default to "equity" settings since corporate
actions are only available for Direct Equity.

 

Use the Type filter to select the type of corporate actions (Bonus,
Consolidation, Dividend, Split). You can select one or multiple options
from the dropdown list.

**Step 3**

Select the required Account and Holding Name.

The Account filter dropdown will display a list of accounts as per the
selected Entity or Group. You can choose one or multiple accounts.

The Holding Name filter dropdown allows you to select all holdings or
specific ones based on the selected Account.

![](media/image2.gif){width="6.268055555555556in" height="3.29375in"}

**Step 4**

**Date Range Filters **

You can either choose from the predefined options in the Date Range
dropdown list or manually select the dates using the Date From and Date
To fields.

The Date Range filter offers several predefined options to simplify your
selection:

1.  **MTD **(Month to Date)**:** Automatically selects the start of the
    current month to today\'s date.

2.  **Previous Month:** Selects the entire previous month, from the 1st
    to the last day.

3.  **QTD **(Quarter to Date)**:** Chooses the start of the current
    quarter to today\'s date.

4.  **Previous Quarter:** Covers the entire previous quarter, from the
    first to the last day.

5.  **Custom:** Allows you to manually choose any specific date range.

Example 1**: **When you select a predefined date range (e.g., Previous
Month), the system will automatically populate the Date From and Date To
fields with the relevant dates. For instance, if you select Previous
Month in September, the system will set Date From to August 1st and Date
To to August 31st.

**Manual Date Selection**

If none of the predefined options fit your needs, select \"Custom\" from
the Date Range dropdown. You can then manually set your desired start
and end dates using the Date From and Date To fields.

**Important Note:**

**90-Day Restriction for All Entities/Groups:** If you are processing
corporate actions for All Entities or a Group, the system restricts the
custom date range to a maximum of 90 days. This means you cannot select
a date range longer than 90 days for these categories. However, this
restriction does not apply when processing actions for individual
entities.

**Step 5**

The Status filter defaults to \"All,\" but you can filter by Processed
or Unprocessed corporate actions. The system will display data according
to the selected Status filter.

**Step 6**

 

Select the TDS value (0% or 10%) from the dropdown list.

The TDS amount will be computed based on the selected percentage for the
Dividend Payout transaction type.

For other corporate actions like Split, Bonus, & Consolidation, the TDS
column will remain blank.

**Note:** You can overwrite the TDS value for unprocessed dividend
payouts but ensure to click Process to save your changes.

 

**Step 7**

If you select Yes in the Process Payouts to Receivable A/Cs dropdown,
the system posts dividend transactions in the Dividend Receivable --
Direct Equity ledger.

Select No to post dividend transactions in the default Payee/Payor/Bank
ledger tagged to the custodian account.

**Processing corporate actions**

**Step 8**

After setting all the filters and configurations, proceed with
processing the corporate actions.

Expand and select all corporate actions, then process this.

![](media/image5.png){width="6.268055555555556in"
height="3.5256944444444445in"}The status of each corporate action will
change to 'Processed'.

![](media/image6.png){width="6.268055555555556in"
height="3.5256944444444445in"}

**Viewing corporate actions**

**Step 9**

Once the corporate actions are processed, you can see the transactions
in the 'Direct Equity' module.

*Note: Corporate actions processed from the corporate action screen will
be posted as of \'Ex date\' in the 'Transaction Date' column. *
