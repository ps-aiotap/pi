The AV system can load positions for multiple entities ('Groups' and
'All Entities') allowing users to 'multi-edit' positions across these,
for various position tags like 'Sector', 'Strategy', 'Asset class',
'Benchmark', 'custom position tags', and more.

*For detailed information about 'Custom Position Tags', please refer
to [this
article.](https://support.assetvantage.com/hc/en-us/articles/6752748831133-Custom-Positions-Tags-user-defined-To-categorize-positions-for-various-analytics-reports-)*

**Finding the Position master**

**Step 1**

Setting up the 'User Access Profile'.

*For detailed information about 'User Access Profiles', please refer
to the [User access permission
article](https://support.assetvantage.com/hc/en-us/articles/360018470337-Setting-up-users-to-access-the-system-with-their-own-login-credentials-to-assign-user-level-profile-permissions-Admin-Read-View-Edit-Delete-etc-).*

**Step 2**

Finding the Position master.

- Navigate to the Position master by going to \'Menu\', then \'Masters\'
  and finally, \'Positions\'.

![](media/image1.png){width="6.268055555555556in"
height="3.122916666666667in"}

**Multi-editing position master tags**

**Step 3**

Loading position master for entity/entities:

- Upon clicking on 'Positions', the below screen will appear, where the
  users can select either an individual entity, a group entity, or 'All
  Entities'.

![](media/image2.png){width="6.268055555555556in"
height="2.8979166666666667in"}

- Under 'Group', all entities and their positions will be visible to
  users as per the user access permission.

- The 'Entity' column has been added for users to check the name of
  entities against the position master.

![](media/image3.png){width="6.268055555555556in" height="2.89375in"}

 

**Step 4**

Editing multiple positions across entities.

- Users can edit multiple position masters across entities selected.

- Users must select the position masters which are to be edited and
  click on the 'Edit' button. Upon clicking 'edit', the below warning
  will appear.

![](media/image4.png){width="6.268055555555556in"
height="2.8722222222222222in"}

- Clicking the 'OK' button will bring up the below position edit screen
  pop-up.

![](media/image5.png){width="6.268055555555556in"
height="3.173611111111111in"}

- To change the desired field, users must select the check box and then
  click on the 'Save' button to see their changes.

*Note: that user will only be able to edit fields with check box in
front of them.*

![](media/image6.png){width="6.268055555555556in"
height="3.1944444444444446in"}

**Additional Filters**

- Users will be able to see the positions for a selected date range
  using the 'Create/Update Date' of positions.

![](media/image7.png){width="6.268055555555556in"
height="2.859722222222222in"}

- Users can choose to either 'Create' or 'Update' the date and
  accordingly select the 'From' and 'To' date range.

- The filter will be applied for the selected option within the given
  date range, and positions will appear accordingly.

- While selecting the date range, users must keep the following in mind:

1.  if users define both 'From' and 'To' dates, then the data will
    appear for the selected date range.

2.  if users leave both the 'From' and 'To' date range blank, then all
    available data will appear.

3.  if users define only the 'From' date and leave 'To' blank, then data
    will appear from the given 'From' date till the latest available
    record.

4.  if users define only the 'To' date and leave 'From' blank, then data
    will appear from inception till the date defined.

![](media/image8.png){width="6.268055555555556in"
height="2.872916666666667in"}

*Note: Transactions Count, Latest Transaction Date and Latest Updated
Date columns are shifted to show columns and by default it will be
unselected; user can select if they wish to see data pertaining the
same.*
