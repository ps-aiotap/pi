A benchmark is a standard against which the performance of a stock,
mutual fund or investment manager can be measured. In AV, the default
benchmark will be set to none, although it can be adjusted to align with
chosen benchmarks that reflect both your investment preferences and your
investment manager\'s strategy. 

**Setting up Benchmarks**

**Step 1**

 Following are the steps to apply the Benchmark at position level:

 Select Menu \> Masters \> Positions

**Step 4**

Once you setup the benchmarks from master, follow below steps to process
reports (PPS and MPPR) to see benchmark returns,

1\. Go to Menu \> Analytics \> Portfolio Performance report, make sure
you have selected PME benchmark option from \'Show Columns\'

![](media/image6.png){width="4.118055555555555in"
height="5.631944444444445in"}

![](media/image7.png){width="6.268055555555556in"
height="2.3354166666666667in"}

2\. Go to Menu \> Analytics \> Multi-Period Performance Report and make
sure you have selected \'Benchmark\' from show columns.

![](media/image8.png){width="4.118055555555555in"
height="5.868055555555555in"}

![](media/image9.png){width="6.268055555555556in"

**Notes**

In case user doesn\'t want to tag any Benchmark at Position level then
user can select \'None\' from dropdown values. With \'None\' option
Benchmark TWR and PME Benchmark IRR will not be computed at position or
at grouping levels.
