**Steps to provide specific access**

Menu Path: **Menu **\> **Settings **\> **User**

To assign specific Entities/Groups that a user can view, first locate
the list of users that appeared on your screen using the menu path
above.

**Step 1**

Locate a particular user and click on the first gear icon -- the 'User
Access Permission' button.

**Step 2**

In this function, you can edit the Entities/Groups the user can view by
adding/removing from the view menu (Pictured Below). The 'Selected
Entity/Group' right-hand pane indicates the Entity/Group(s) the user
currently has access to. By adding/removing from view, click the entity
and the desired permission.

**Step 3**

Click 'Save' to complete these permissions.
