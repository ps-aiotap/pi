**How to set up users**

This article will walk you through the essential steps involved in
setting up a new user in the AV system, along with their 'role' and
access profile permissions, customizable as per your requirement.

**Creating new users and checking existing user access**

**Step 1 **

Go to \'Menu\', 'Settings', and then 'User' to view your existing users,
or add more users by clicking the '+' sign.

![](media/image1.gif){width="6.268055555555556in"
height="3.5256944444444445in"}

**Step 2**

In the pop-up dialogue box that opens, fill in the new user\'s details. 

![](media/image2.png){width="6.268055555555556in"
height="3.452777777777778in"}

- **User Role:** This can be assigned to user as per the access profile
  created. 

*Note: Depending upon the user role selected, your user can be assigned
access permission, which is also customizable (see step 5). *

![](media/image3.png){width="6.268055555555556in"
height="3.452777777777778in"}

- **'Active' Checkbox:** Click the \'Active\' checkbox to register this
  new user as active.

![](media/image4.png){width="6.268055555555556in"
height="3.452777777777778in"}

- **Default Entity:** Choose an 'Entity' as the default entity for all
  list screens and report filters.

![](media/image5.png){width="6.268055555555556in"
height="3.452777777777778in"}

-  **Date', 'Time', and 'Number' Format:** Select a specific date, time,
  and number format to display on reports and list screens.

![](media/image6.png){width="6.268055555555556in"
height="3.452777777777778in"}

**Step 3**

After entering all the required details, click 'Save'.

![](media/image7.png){width="6.268055555555556in"
height="3.452777777777778in"}

**User Access Profile  **

**Step 4**

Visit your users\' access and permissions by clicking \'Settings\' and
then \'User Access Profile\' to view existing profiles. More profiles
can be added by clicking the \'+\' button.

![](media/image8.gif){width="6.268055555555556in"
height="3.5256944444444445in"}

**Step 5**

Now, in the pop-up dialogue box that opens, fill in the profile name; as
per your preference, you can check/uncheck the entire column or even go
individual module-wise.

![](media/image9.png){width="6.268055555555556in"
height="3.452777777777778in"}

**Step 6**

Click the edit button to update or edit any user access rights.

![](media/image10.png){width="6.268055555555556in"
height="3.303472222222222in"}

**Step 7**

Finally, after selecting all required details, click 'Save'.

![](media/image11.png){width="6.268055555555556in"
height="3.452777777777778in"}

**We hope you are successfully able to create new users and manage their
user access profiles. Still have questions? Feel free to reach out to
AV\'s Customer Success Team.**
