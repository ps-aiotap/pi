Check print will enable you to print checks from AV system in required
format.

**User Access Profile**

- Go to Menu \> Settings \> User Access Profile

- You can edit an existing profile or can create a new one by clicking
  on the "+" sign

- With access to print you can print the checks and with access to void
  you can void the checks.

![](media/image1.jpeg){width="6.268055555555556in"
height="1.7354166666666666in"}

**Enabling Check Print**

Account Master helps you to create and manage Bank account from which
you want to allow to print checks.

- Go to Menu \> Masters \> Accounts

- You can edit an existing account or can create a new one by clicking
  on the "+" sign

- To enable the Bank account to print checks, enable the Print Checks
  box

![](media/image2.jpeg){width="6.268055555555556in"
height="3.2916666666666665in"}

 

**Setting up Checkbook Master**

The checkbook master helps to create and manage multiple checkbooks for
different or same accounts.

- Go to Menu \> Masters \> Checkbook

- To create the checkbook, click on the "+" sign on the top right corner

- Account dropdown will only contain those Bank account which are
  eligible for printing checks.

- Enter the series of the checkbook. You can also create different
  series of checks from same account. If you exhaust the series, system
  will automatically take the next running series.

- Select from our list of Templates, which best suits your current
  checkbook format.

- Select the address of the bank. You can add new address from Menu \>
  Masters \> Address.

- Default check will always use the defaulted checkbook master for the
  selected account, you can select only one checkbook master as default
  for the account.

![](media/image3.jpeg){width="6.268055555555556in"
height="3.0944444444444446in"}

**Editing Checkbook Master**

- Once you have setup a checkbook master and printed a check, you have
  limited fields to edit it.

- If you want to edit Next/Running series, then you should have special
  permission which is a 'Checkbook Running Series'.

![](media/image4.jpeg){width="6.268055555555556in" height="3.06875in"}

- Want to see the permission status? Check your permission status in the
  'User Access Permission' section. *For more details, please refer to
  the [User access permission
  article](https://support.assetvantage.com/hc/en-us/articles/360018470337-Setting-up-users-to-access-the-system-with-their-own-login-credentials-to-assign-user-level-profile-permissions-Admin-Read-View-Edit-Delete-etc-).*

-  With permission you can see the lock button in front of 'Checkbook
  Running Series' field and upon clicking it is allowed to enter a
  series number which is greater than the current/existing series number
  and should be within the From and To numbers defined for respective
  checkbook master.

![](media/image5.jpeg){width="6.268055555555556in"
height="2.796527777777778in"}

**Editing Check transaction post printing**

- Once you have printed the check from the system, you have a limited
  field to edit/correct the check.

- If you want to edit Ledger Account, Check Number and Memo, then you
  should have special permission which is a 'Check Transaction'.

![](media/image6.jpeg){width="6.268055555555556in"
height="3.207638888888889in"}

- Want to see the permission status? Check your permission status in the
  'User Access Permission' section. *For more details, please refer to
  the [User access permission
  article](https://support.assetvantage.com/hc/en-us/articles/360018470337-Setting-up-users-to-access-the-system-with-their-own-login-credentials-to-assign-user-level-profile-permissions-Admin-Read-View-Edit-Delete-etc-).*

- With the  permission you can see the lock button in front of Ledger
  Account, Check Number and Memo fields and upon clicking it is allowed
  to edit.

![](media/image7.jpeg){width="6.268055555555556in" height="3.23125in"}

**Writing Check**

You can write check out of Bank, Credit Card & Cash transactions.

- Menu \> Transactions \> Bank, Credit Card & Cash

- To enter the transaction, click on the "+" sign on the top right
  corner

- Enter all the details along with notes and memo and can also upload
  documents pertaining to check. Save the transaction and check is ready
  to print

- Please note Payee / Payor /Vendor is a mandatory field for check
  transactions

![](media/image8.jpeg){width="6.268055555555556in"
height="3.165277777777778in"}

**Print Preview**

It helps you to see the check before it gets printed. You can check if
all the fields are correct or correctly placed and if not, then you can
make necessary changes.

- Select the Bank account, Type as 'Check' and Status as 'P : To Print'.

- Once selected, Print button will be enabled for printing/previewing
  (its required to select the account, transaction type and status as P
  : To Print otherwise print button will not be enabled).

- You can select multiple check transactions and preview them
  simultaneously.

![](media/image9.jpeg){width="6.268055555555556in"
height="1.8034722222222221in"}

- Below window will be visible once clicked on print button and from the
  dropdown given, you can select the checkbook from which you want to
  preview the check.

- Please select 'Print Vouchers on All Checks' to preview the voucher
  information on the stub of the check.

![](media/image10.jpeg){width="6.268055555555556in"
height="3.057638888888889in"}

- You can then click 'Print Preview' button to view how your check will
  print. Below is the sample of the print preview.

**Note:** You can download and save the check from preview window for
reference. Saved check from preview contains draft watermark to
distinguish it from the actual check.

![](media/image11.jpeg){width="6.268055555555556in"
height="3.196527777777778in"}

 

**Printing Check**

It helps you to print the hard copy of the check

- Select the Bank account, Type as 'Check' and Status as 'P : To Print'.

- Once selected, Print button will be enabled for printing and you can
  print check by clicking on the same (its required to select the
  account, transaction type and status as P : To Print otherwise print
  button will not be enabled).

- You can select multiple check transactions and print them
  simultaneously (checks will print on individual pages except for the
  templates which has 2 or 3 checks supported).

![](media/image9.jpeg){width="6.268055555555556in"
height="1.8034722222222221in"}

- Below window will be visible once clicked on print and from the
  dropdown given, you can select the checkbook from which you want to
  print the check. Also, it shows the bank balance after the checks.

- Please select 'Print Vouchers on All Checks' to print the voucher
  information on the stub of the check.

**Marking Check transactions as cleared**

In Bank & Cash Transaction, : Cleared checks indicates that funds were
cleared from bank account.

Check transactions with status R: Released can only be cleared.

It can be cleared from bank & cash transaction screen.

**Bank & Cash Transaction screen**\
You should edit R: Released check or filter using status column and
click on \'Clear Checks\' icon.

![](media/image14.jpeg){width="6.268055555555556in"
height="2.227777777777778in"}

After clicking on \'Clear Checks\', a pop up appears with an option
either to select date by making use of calendar drop down or Transaction
date.

![](media/image15.jpeg){width="6.268055555555556in"
height="3.017361111111111in"}

![](media/image16.jpeg){width="6.268055555555556in"
height="2.154861111111111in"}

On selection of date system will validate you with above message and on
selection of 'Clear' button check transaction will be updated with
Status as 'C : Cleared'. Cleared date will be reflected on list screen
under status.

**Voiding a Check**

Checks which are printed are allowed to mark as void due to any errors
or needs to be marked as cancelled due to various reasons.

Check transactions with status R: Released can only be voided.

You will need to edit R: Released transaction where option of void is
available.

![](media/image17.jpeg){width="6.268055555555556in"
height="2.9138888888888888in"}

After clicking Void, you will get an option to void the check
transaction on either Today's date or Transaction date.

![](media/image18.jpeg){width="6.268055555555556in"
height="2.936111111111111in"}

After voiding a transaction, status of transaction changes to V: Void
with void date beneath and void voucher is created to reverse the
original accounting entries.

![](media/image19.jpeg){width="6.268055555555556in"
height="3.033333333333333in"}

**Note:** Check transaction with status R : Reconciled cannot be voided.
In order to void check transactions with R : Reconciled, you should
un-reconcile the transaction from Bank Reconciliation and then void the
same.
