A heat map is a data visualization tool that uses color gradients to
represent the intensity of values, making it easy to identify patterns,
trends, or outliers. It visually shows higher values in
darker colors (E.g., green) and lower values in lighter colors (E.g.,
red or pink). The Heat Map chart in the Multiple Period Widget allows
you to easily visualize investment performance over time

**5. View the Heat Map** 

Once you've configured your heat map, here's what it will display: 

a.  **Primary Grouping on the Y-Axis**: 

- The **Primary Grouping** (e.g., **Asset-Class**) will be shown along
  the **Y-Axis**. 

![A screenshot of a computer screen AI-generated content may be
incorrect., Picture](media/image12.png){width="6.268055555555556in"
height="3.075in"} 

 

b.  **Time Period on the X-Axis**: 

- The **period** (e.g., **March 2024 or a quarter period**) will be
  displayed on the **X-Axis**. 

c.  **Grid Box Colors**: 

- Each grid box represents the performance of a specific asset class for
  a particular period. The color of each box indicates performance: 

<!-- -->

- **Lighter colors**: Lower values. 

- **Darker colors**: Higher values. 

- E.g- User has selected color code as green for highest positive value
  and pink for lowest negative value value. 

***Note**- the above *colors* are only an example to illustrate, the
grid will display colours based on what the user has selected.*
