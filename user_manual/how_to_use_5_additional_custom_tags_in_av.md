Position Tags in Asset Vantage offer a powerful way to categorize and
group assets within your portfolio, enabling enhanced reporting and
analysis. This guide will help you understand the new feature that
introduces five additional custom tags, giving you more flexibility to
organize your data and tailor reports to your specific requirements.

**Step 1: Access Position Tags**

**              **Path: **Menu **\> **Masters **\> **Position Tags**

Here, you'll see a list of the existing Position Tags (Position Tag 1 to
Position Tag 5), along with the newly added ones (Position Tag 6 to
Position Tag 10).       

                                             
 ![](media/image1.jpeg){width="6.263888888888889in"
height="3.0694444444444446in"}

**Step 2: View and Manage Existing Tags**

- You can edit the default Position Tags (Position Tag 1 to Position
  Tag 5) to match your specific needs. Just click the edit
  button **(**![](media/image2.png){width="0.1527777777777778in"
  height="0.13194444444444445in"}**)**. These tags can be used for
  categories like Market Cap, ESG Ratings, Family Strategic Themes, and
  more.

![](media/image3.jpeg){width="6.263888888888889in"
height="3.0694444444444446in"}

**Step 3: Adding Custom Position Tags **

- You now have access to five new custom Position Tags --- Position Tag
  6 to Position Tag 10. These are ready to use and can be customized to
  fit your reporting needs.

- By default, they are named Position Tag 6, Position Tag 7, Position
  Tag 8, Position Tag 9, and Position Tag 10.

- To rename any of these, click the edit
  button **(**![](media/image2.png){width="0.1527777777777778in"
  height="0.13194444444444445in"}**)**. A pop-up will appear where you
  can enter a new name --- for example, "Manager" or "Region" --- based
  on how you want to use the tag in your reports.  

![](media/image4.jpeg){width="6.263888888888889in"
height="3.0694444444444446in"}                                         
               

                                                                        

**Step 4: Adding Values to Position Tags**

- After naming your Position Tags, you can assign sub values to them.
  For example, if you create a tag called "Asset Categorization," you
  can add sub values like "Large Cap," "Mid Cap," and "Small Cap."

- To add a value, click the plus
  icon** (**![](media/image5.png){width="0.1527777777777778in"
  height="0.16666666666666666in"}**)** next to the Position Tag, and
  type in the value (e.g., "Large Cap")

*Note: You can use the dropdown search to quickly find values and save
time.*

![](media/image6.jpeg){width="6.263888888888889in"
height="3.0694444444444446in"}     

**Step 5**: **Assigning Position to Specific Transactions Under Entity**

Path**: Menu **\> **Masters **\> **Positions**

- Click the edit
  icon **(**![](media/image7.png){width="0.1527777777777778in"
  height="0.13194444444444445in"}**)** to the left of any existing
  position.

<!-- -->

- Once the pop-up opens, you will see the 5 existing Position Tags along
  with the 5 new custom tags. When you click on any Position
  Tag **(**![](media/image8.png){width="0.16666666666666666in"
  height="0.1736111111111111in"}**)**, its dropdown values will appear.

- You can select any dropdown value, and it will be saved for that
  specific Position Tag. For example: You click on the "Market Cap"
  Position Tag and choose "Large Cap" from the dropdown. This will be
  saved for that tag.

 

            ![](media/image9.jpeg){width="6.263888888888889in"
height="3.0694444444444446in"}

**Step 6: Using Position Tags in Analytics and Reports**

**             **Path**: Menu **\> **Report Book**

**             **Path**: Menu **\> **Analytics**

- Once you set up the Position Tags, you can use them to filter and
  group data in reports. For example: In reports like Wealth Register or
  Portfolio Performance Summary, you can filter by the Position Tags you
  created.

- The Position Tags will appear in the primary and secondary grouping
  filters and the subgroup filter, making it easy for you to categorize
  your data.

![](media/image10.jpeg){width="6.263888888888889in"
height="3.0694444444444446in"}

*Note: The above snips are examples for Report Book. In a similar
fashion, you can navigate to **Masters **\> **Analytics **as well, using
the same functionality to view reports.*

**Step 7: Organizing Tags Using Drag and Drop**

- You can also organize the order of your tags using the drag and drop
  feature while creating them under **Masters **\> **Position Tags**

- Simply drag the tags within the Position Tag Master to reorder them.
  This allows you to prioritize the tags that matter most.

![](media/image11.jpeg){width="6.263888888888889in"
height="3.0694444444444446in"}

**Step 8: Viewing Position Tags in the Grid View**

- In the Grid View of reports, the newly added Position Tags will appear
  as additional columns.

- If you select All Position Tags, the newly added tags will appear next
  to the existing ones.

![](media/image12.jpeg){width="6.263888888888889in"

**Step 9: Exporting Reports with Position Tags**

- You can export reports that include your Position Tags to Excel or CSV
  formats.

***Notes and Best Practices***

- *Avoid Duplicates: Make sure you avoid using the same name as other
  existing tags to prevent duplication errors.*

- *Drag and Drop: You can use the drag-and-drop feature to arrange tags
  in the reports as per your preference.\*

*This feature makes Asset Vantage's reporting and analysis even more
customizable to meet your specific portfolio needs.*
