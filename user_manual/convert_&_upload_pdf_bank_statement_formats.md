**Finding the File Converter**

Go to **Menu** \> **Transactions **\> **select File converter**.

![](media/image1.png){width="6.268055555555556in"
height="2.8777777777777778in"}

**Uploading Bank Statement**

**Step 1**

- Upload the Bank statement, then click
  on ![](media/image2.jpeg){width="0.4236111111111111in"
  height="0.3541666666666667in"} check icon to process.

- If the file is password protected, please select check box and mention
  the password before processing the file.

![](media/image3.png){width="6.268055555555556in"
height="2.2958333333333334in"}

**Step 2**

- Once file is processed, system will generate zip folder.

- Extract the zip folder and open the excel file which has Assetvantage
  Bank mentioned in it.

![](media/image4.png){width="6.268055555555556in"
height="1.1555555555555554in"}

**Step 3**

- Open the excel & make sure entity name, bank name & account number is
  same which you have created in masters.

- Check the date format, it should be in dd-mmm-yyyy format.

![](media/image5.png){width="6.268055555555556in"
height="1.1194444444444445in"}

**Uploading the transactions**

**Step 4**

- Save the transaction file in your drive.

- Upload bank transactions from **Menu **\> **Transactions **\> **Bank,
  credit card, cash module**.

![](media/image6.png){width="6.268055555555556in"
height="1.082638888888889in"}

**Step 5**

- Once you upload the file, system will give you following error "
  Ledger Account name required", "Incorrect Ledger Account Number".

![](media/image7.png){width="6.268055555555556in"
height="2.4194444444444443in"}

**Step 6**

- Edit the transactions & tag respective ledger account.

- Once the ledger account is tagged, save the transaction.

![](media/image8.png){width="6.268055555555556in"
height="2.2430555555555554in"}

**Processing transactions**

**Step 7**

- Once you add ledger account in every transaction, transactions will
  reflect in Green color.

- You can now select all the transactions & click on process.

- Once transactions are processed, you can view the transactions from
  details tab.

![](media/image9.png){width="6.268055555555556in" height="2.625in"}

**We hope you are now ready to successfully convert & upload PDF and
