A few geographies like Canada and Middle east follow average cost method
to calculate capital gains. In USA also, specific DRIP equities, Mutual
Funds and ETFs follow average cost method.

Average cost basis method allows users to maintain cost basis on balance
sheet on a running average purchase cost. The system will calculate the
average cost whenever there is a purchase/
transfer-in/split/bonus/consolidation/Merger/De-merger / Div
reinvestment / Transfer-in transaction. For any Sell / Transfer-out
transaction, the system will take the latest updated average cost.

 

**Using Average Cost Method**

**Account wise**

- Option 1 : Users can choose to track all (MF & Stock) securities in an
  account with average cost basis.

- Option 2 : Only specified MF & Stock securities in an account can be
  switched to being tracked on  average cost basis in an account that is
  otherwise FIFO/MGHC/etc.

**Working of Average Cost**

- All new purchases will change the average cost.

- Any sell will not impact the average cost.

- A close out of a position (last lot sold) will re-set the average cost
  in case security is re-purchased in that account.

- Cost Basis Adjustment transaction is available on top to impact any
  overall cost adjustment.

**Impact on Performance**

- No change in security performance as performance is only on cash
  flows.

**Impact on Gains Report / Tax Gain**

- Option 1 : User has the option to run gains / losses on the balance
  sheet cost basis for each sold tax lot.

- Option 2 : User has the option to run gains / losses on the basis of
  FIFO / MGHC despite the cost basis of the position being maintained on
  the balance sheet being average cost (Alternate basis).
