**Enable Two Factor Authentication**

AV supports two factor authentication for secured access.

Refer to the following steps to enable two factor authentication for
your user login.

Menu** **Path**: *Menu ****\> **Settings **\> **User** \> **User** **profile**. *

![](media/image1.png){width="6.268055555555556in"
height="4.165972222222222in"}

- Enable Mobile SMS and/or Email ID as the Two Factor Authentication
  desired by ticking against the designated boxes. Please make sure that
  valid email ID and phone number (along with a mandatory ISD code eg:
  +1 for US & Canada, +44 for UK, +971 for UAE, +91 for India) are
  updated in the user profile to receive the authentication code to the
  mentioned ID/Phone number. Please do not keep any spaces between ISD
  code and phone number.

- Post enabling, user will receive an SMS and/or email asking for
  verification of the mobile number and/or email ID. Once user clicks on
  the link provided, email ID and/or Mobile number will be successfully
  verified and Two Factor Authentication will be enabled.

- On the next user login, the system will ask for a 6-digit
  authentication code (One Time Passcode or OTP) which will be sent via
  SMS and/or Email to the verified mobile number and/or email ID as per
  the options selected.  Only when user enters the correct 6-digit
  authentication OTP, system will allow the user to log-in.

- This OTP code will be only valid for 100 seconds, post which the code
  expires and will need to be regenerated from log-in page by clicking
  the "Re-Generate" button on the login page.

- User can disable their own Two Factor Authentication login mode by
  un-checking the designated boxes in the user profile.

- In case user wants to change email ID or Phone number for Two Factor
  Authentication they can change the required details on user profile.
  User will receive verification link on new email or phone number for
  verification. Post verification user will receive authentication OTP
  on updated email ID / Phone number.

*Note**:** Newly created users will have default two factor
authentication enabled for both Mobile and Email ID and user can choose
not to opt for the same.*
