**Account Setup**

For speculative transactions user should mark \'Asset : Custodian\' as
speculative account.

- Go to **Menu** \> **Masters** \> **Accounts**.

![](media/image1.png){width="6.268055555555556in"
height="3.5347222222222223in"}

**Uploading contract note**

- **Menu** \> **Transactions** \> **Direct Equity** \> **Contract
  Note**.

- Select format of contract note whether HTML or PDF, broker\'s name and
  type as Speculative Contract Group.

![](media/image2.png){width="6.268055555555556in"
height="1.4583333333333333in"}

- Click on edit icon to enter details of custodian, Payee/Payor/Bank and
  Speculative accounts.

- Default Payee/Payor/Bank account mapped to Custodian account will
  appear in Payee/Payor/Bank account field.

![](media/image3.png){width="6.268055555555556in"
height="2.3520833333333333in"}

**Processing transactions**

- Once details of accounts are updated, save the details and close
  window. Updated Contract note transactions will turn in green which
  are ready to process.

- Select transactions and click on process button.

![](media/image4.png){width="6.268055555555556in"
height="1.0041666666666667in"}

- Transactions will appear on transaction screen.

- **Menu** \> **Transactions **\> **Direct Equity** \> **Details**.

![](media/image5.png){width="6.268055555555556in"
height="1.2638888888888888in"}

- Click on edit screen to view transactions and voucher icon to view
  voucher details.

![](media/image6.png){width="6.268055555555556in"
height="3.698611111111111in"}

![](media/image7.png){width="6.268055555555556in"
height="3.4138888888888888in"}
