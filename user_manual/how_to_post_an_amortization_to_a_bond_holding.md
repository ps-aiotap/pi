Amortization is an accounting technique used to lower the cost basis of
a bond, loan or fixed asset over a set period of time.

**Applicability and Usage**

In AV, an Amortization transaction is supported for Bonds & Debentures,
Optional Fully Convertible Debentures, Commercial Paper and Certificate
of Deposits investment vehicles in AV.

An Amortization transaction can be used to adjust the purchase premium
or discount over the face value of a bond for a period of time. Users
can post both positive or negative amount adjustments along with
adjustment for quantities.

**Post Amortization Transaction**

**Step 1**

- Go
  to **Menu** \> **Transactions **\> **Fixed** **Income **\> **Bonds & Debentures**.

- Click on '+' sign.

![](media/image1.png){width="6.268055555555556in"
height="2.2291666666666665in"}

**Step 2**

- Select Transaction Type ' Amortization.

- Select the account for which you want to post Amortization.

- Default Payee/Payor/Bank account will be " Bond Amortization Expense "
  but user can select any other ledger.

- Select the transaction date at which Amortization transaction will be
  posted and further select the Security name.

![](media/image2.png){width="6.268055555555556in"
height="3.2020833333333334in"}

**Entering Amortization**

**Step 3**

- System will show available open lots with Buy date, Open quantity, Buy
  Price and Tax Basis.

- User can enter quantity to be adjusted and or Amortization amount; and
  system will auto compute adjusted remaining quantity adjusted price
  and tax basis.

- Through this process user can enter amortization for multiple lots if
  there are any.

![](media/image3.png){width="6.268055555555556in"
height="3.2020833333333334in"}

**Step 4**

- Save the transaction to update the Amortization amount/quantity.

- User can see the voucher on Details list screen to see the effect on
  Custodian and selected Payee/Payor/Bank account.

**Impact on Reports**

**Wealth Register / Balance Sheet / Gains Report**\
From the date of Amortization transaction, the cost price / purchase
amount will be adjusted as per the Amortization transaction. In case of
multiple Amortization transactions, system will take the last adjusted
price and adjusted purchase cost (Tax Basis).

Gains (Realized / Unrealized) will be computed using adjusted cost and
not the original purchase cost.

Accounting reports will not have any impact if only quantity is
amortized and only holding quantity and cost per price will be updated.

**Portfolio Performance**\
Performance report will not have any impact if only amortization amount
is adjusted. In case of adjusted quantity there will be an impact on
performance computation where adjusted quantity will be considered.
