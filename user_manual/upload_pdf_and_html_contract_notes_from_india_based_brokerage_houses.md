Please follow below mentioned steps to upload PDF/HTML contract notes
through converter.

**Upload Contract Note**

**Step 1**

 Go to **Menu **\> **Transactions **\>** Direct Equity**.

![](media/image1.png){width="6.268055555555556in"
height="2.640277777777778in"}

**\
Step 2**

Go to Contract Notes tab from top right side.

![](media/image2.png){width="6.268055555555556in" height="0.8in"}

**Step 3**

Please select below fields before uploading the contract note in system.

1.  Entity: Select Entity from drop down then.

2.  Contract Note Type: Select "Converter" as Contract Note Type then.

3.  Account: Select Delivery Custodian/Depository Account from drop
    down.

4.  Payor/payee/bank: Once you select the Custodian/Depository Account,
    payor/payee/bank account will auto reflect.

5.  Once you select all above details, click on upload icon, and select
    PDF/HTML contract notes from folder.

![](media/image3.png){width="6.268055555555556in"
height="0.46805555555555556in"}

![](media/image4.png){width="6.268055555555556in"
height="1.2326388888888888in"}

**Step 4**

Once the contract note is uploaded, you will see the transactions with
green color. You can now select the transactions and click on process
icon.

![](media/image5.png){width="6.268055555555556in"
height="1.5416666666666667in"}

**Step 5**

Once the transactions are processed, you can see the transactions from
Details tab.

![](media/image6.png){width="6.268055555555556in"
height="1.7618055555555556in"}

![](media/image7.png){width="6.268055555555556in"
height="2.6333333333333333in"}
